1. 全体の流れ

見積受注発注仕入先回答納期回答・出荷売上計上・請求入金・返品

見積を入口に、受注・発注・請求までの情報をすべて会社で一元管理します。お客様（工務店・施工店）はお客様ポータルや現場QRから直接注文でき、仕入先は発注書メールのリンクからログインなしで納期・単価を回答します。御社が間に入って転記する仕事がなくなります。

2. はじめにやること（初期設定）

  1. 設定 → 会社情報：会社名・住所・電話・登録番号（インボイス）・振込先を入れます。帳票に印字されます。
  2. 設定 → 営業所・部署・ユーザー：社員のアカウントを作ります。権限（管理者・所長・一般）と表示範囲を設定します。
  3. 得意先：締め日（5・10・15・20・25・末日）と回収条件、担当者、請求書の送付先メールを登録します。
  4. 仕入先：発注書を送るメールアドレスを登録します。
  5. 商品マスター：CSV・Excel で取り込めます（見出し：メーカー・品番・品名・仕様・単位・定価・値引きコード・仕入掛率・仕入先・在庫数）。初回は当社でお預かりして取り込みます。
  6. 掛率：得意先×メーカー×値引きコードごとの売掛率を登録すると、見積・受注で自動で入ります。
  7. 得意先 → 現場・倉庫・ポータルのアカウント：お客様にポータルを使ってもらう場合はアカウントを作成し、現場ごとの QR を印刷して渡します。

3. ダッシュボード

朝ダッシュボードを開けば、要対応（お客様からの注文・発注待ち・下書きのままの発注・納期未連絡・出荷指示待ち・売上未計上・取消変更の依頼・動いていない見積）と、相手の返事待ち（仕入先の回答待ち・出荷待ち・入金期日超過）の件数が並びます。カードを押すと該当の一覧が開きます。右上で「自分の担当・自営業所・全社」を切り替えられます。

4. 見積

AI読み取りで見積を作る

  1. メニュー「AI読み取りで見積」を開き、仕入先の見積書（PDF・Excel・画像・写真）をドラッグします。複数枚まとめても構いません。
  2. AIが品番・品名・数量・定価・掛率・値引後単価を読み取ります。明細の合計と紙面の小計が一致するかが表示されます。自信のない行には「要確認」の印が付きます。
  3. 仕入先を確認して「チェックした明細を取り込む」を押すと、仕入単価として明細に入り、掛率マスターから売掛率が自動で入ります。
  4. 得意先・件名を入れて保存します。

AI読み取りは成功した1枚ごとの従量です。失敗・読み直しは数えません（設定画面で利用状況を確認できます）。

品目編集と掛率

  • 品番を入れると商品マスターの候補が出ます。選ぶと定価・仕入先・仕入掛率が入ります。
  • 仕入掛率・売掛率（%）を入れると単価と利益率が自動計算されます。単価を直接入れると掛率が逆算されます。
  • 「掛率を自動設定」で全行に掛率マスターの売掛率を入れます。チェックした行だけ一括で変えることもできます。
  • 行をチェックして「セットに」でまとめると、御見積書ではセット名で1行（一式）になります。内訳の表示・非表示も選べます。

御見積書・版管理・状態

  • 「御見積書PDF」で印刷用の画面が開きます。ブラウザの「印刷 → PDFに保存」で PDF になります。
  • お客様に出した版は「提出版にする」。内容を変えるときは「新しい版を作る」で、元の版はそのまま残ります。
  • 状態は「下書き・商談中・受注確定・失注」。失注のときは理由を残すと見積分析に集計されます。
  • 「受注にする」を押すと、明細・単価・仕入先がそのまま受注になります（二度打ち不要）。

見積分析

担当者別・得意先別・営業所別・日別・月別に、見積の件数と金額・受注率・失注件数・商談中の金額・粗利率を確認できます。

5. 受注

  • 受注の入口は「見積から」「お客様ポータル」「現場QR」「社内入力（電話・FAX）」の4つです。
  • ポータル・QRの注文は価格が未定の状態で届きます。「売単価の一括登録」で単価を入れ（掛率で一括も可）、「お客様へ価格を回答」を押すとメールで回答し、ポータルにも金額が表示されます。
  • 画面上部の進み具合（受注 → 価格確定 → 発注 → 仕入先回答 → 納期連絡 → 出荷 → 売上計上 → 請求）で、いまどこにあるかが分かります。
  • お客様からの取消・変更の依頼は受注画面の上部に表示されます。「承認」「却下」で回答するとメールで通知されます。取消を承認すると発注済みの仕入先にも取消メールが送られます。

6. 発注と仕入先の回答

  1. 受注画面で「仕入先ごとに発注して送信」を押すと、未発注の明細が仕入先ごとに自動で分かれ、発注書メールが送られます。下書きだけ作ることもできます（発注一覧からまとめて送信）。
  2. 仕入先はメールのリンクを開き、納期・仕入単価・代替品・送料を入力して送信します。ログインもアカウントも不要です。
  3. 回答は自動で受注に反映され、担当者に通知されます。電話・FAXで聞いた場合は「回答を代理入力」で入れられます。
  • 数量の分割発注：明細の「分割」で数量を分け、別の仕入先に手配できます。
  • 自社在庫からの引当：明細の「在庫引当」で商品マスターの在庫から引き当てます。
  • 在庫補充・枠取り：発注一覧の「在庫補充・枠取りの発注」から受注に紐づかない発注を作り、届いたら「入荷処理」で在庫に加えます。

7. 納期連絡・出荷指示・納期カレンダー

  • 仕入先の回答がそろったら受注画面の「お客様へ納期を送る」で納期をメールします。
  • 出荷指示画面で、回答済みの発注に出荷指示（現場直送など）を出します。仕入先は同じリンクから出荷日・送り状番号を連絡します。
  • 納期カレンダーで、回答された納期を月表示で共有できます。担当者・営業所・お客様で絞り込めます。

8. 売上計上・返品

  • 納品したら受注画面の「売上計上」。出荷済み・在庫引当済みの明細には数量が入っています。一部だけの計上もできます。
  • 計上した売上から納品書を印刷できます。
  • 返品は受注画面の「返品」から。赤伝として次の請求書にマイナス行で載ります。在庫に戻すこともできます。

9. 請求・入金・会計CSV

  1. 請求 → 締めて請求書を作る：締め日の区分と締め日を選び、お客様を確認して作成します。請求済みの売上は二度と請求に入らないため、二重請求・請求もれを防げます。
  2. 請求書一覧で「未送付をメール送付」を押すと、請求書のリンクをお客様に送ります（ポータルでも確認できます）。
  3. 入金・消込：入金を登録して、請求書ごとに消し込みます。多すぎる分は過入金として残り、あとで充当できます。手形・でんさいは期日を入れると「手形・でんさい」画面で期日管理できます。
  4. 会計CSV：請求・売上伝票・入金を、会社ごとに選んだ項目で CSV 出力します（Shift_JIS / UTF-8）。

請求書は適格請求書（インボイス）の記載事項（登録番号・税率ごとの合計と消費税額・取引年月日・内容）に対応しています。消費税は請求書ごとに税率ごと1回で計算します。

10. 予算管理

  1. 予算入力：管理者が全社目標を入れ、営業所へ配分します。上の行が配られた目標、下の行が一つ下の階層への配分で、差が「未配分」として常に見えます。
  2. 年間額を入れると、12等分または前期実績の比率で各月へ按分します。マス目は直接編集でき、自動で保存されます。
  3. 所長・責任者は営業所 → 部署 → 担当者、担当者は自分 → 得意先へと配分し、「締めて提出」。最後に管理者が「確定」します。
  4. 予算進捗：年間と今日までの達成率、月別の予算と実績（累計の線つき）、下の階層別の表。行を押すと部署 → 担当者 → 得意先へ下りられます。未決の見積金額が並ぶので、あといくら受注すれば届くかが分かります。CSV・Excel に出力できます。

得意先の予算は得意先に紐づくため、担当者が代わっても予算と期初からの実績はそのまま後任に引き継がれます。

11. 権限と表示範囲

権限できること
管理者すべての操作。設定・ユーザー管理・予算の確定
所長・責任者自営業所の予算配分（部署・担当者へ）
一般見積・受発注・請求などの日常業務。自分の担当得意先への予算配分

一覧画面の「自分の担当・自営業所・全社」で表示範囲を切り替えます（初期表示はユーザーごとに設定）。退職者のアカウントを停止しても、データは会社に残ります。

12. よくある質問

メールが届かない
設定画面の「システムの状態」でメール送信が「SMTPで送信」になっているか確認してください。「送信記録のみ」の場合はメールは送られず、設定画面の「送信したメール」に記録だけ残ります。
仕入先が回答ページを開けない
発注画面の「リンクをコピー」で回答ページのURLを取得し、別の方法で伝えることもできます。
請求書を作り直したい
最新の請求書から順に「取消」できます。含まれていた売上は未請求に戻ります。
データのバックアップは？
サーバーが毎日自動でバックアップし、直近14日分を保存します。

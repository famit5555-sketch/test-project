# One-Sto Plus（ワンスト プラス）

住宅設備商社のための **見積・受発注・請求クラウド**（フルプラン）。
見積から受注、発注、仕入先回答、請求・入金まで、ひとつの流れで管理します。
お客様（工務店・施工店）と仕入先が直接触れるので、電話・FAX・転記が減ります。

## できること

| 分野 | 機能 |
|---|---|
| 見積 | 仕入先見積書のAI読み取り（PDF・Excel・画像）／品目編集・掛率計算／セット／御見積書PDF／版管理（提出版）／見積分析（担当者・得意先・営業所・日・月別の受注率・粗利率・失注理由）／商品マスター検索・案件マスタ |
| 受注 | 見積から1操作で受注／お客様ポータル・現場QRの注文を自動で受注に／売単価の一括登録と価格回答メール／お客様への納期回答メール／取消・変更依頼への承認・却下 |
| 発注 | 仕入先ごとに自動分割・一括送信／数量の分割発注／仕入先回答の自動反映（ログイン不要の回答ページ）／電話・FAX回答の代理入力／出荷指示／自社在庫からの引当・在庫補充（枠取り）発注と入荷 |
| 売上・請求 | 売上計上（一部計上可）／納品書PDF／締め日ごとの請求書PDF一括作成（二重請求・請求もれ防止）／インボイス対応／請求書のメール送付／会計ソフト向けCSV（項目・文字コードを会社ごとに選択） |
| 入金・返品 | 請求書単位の入金消込・過入金の管理・手形やでんさいの期日管理／売掛残高／返品伝票 → 請求へのマイナス行（赤伝） |
| 管理 | ダッシュボード（今日やること・相手の返事待ち）／予算管理（全社 → 営業所 → 部署 → 担当者 → 得意先の配分、提出・確定、達成率・今日までの達成率、月別グラフ、CSV/Excel出力）／納期カレンダー／権限（管理者・所長・一般）と表示範囲（全社・自営業所・自分）／得意先・現場・仕入先・商品・掛率・案件のマスター／操作マニュアル（商社向け・お客様向け） |

社外向けの画面:

- **お客様ポータル** `/portal/` — 注文（現場を選ぶとお届け先が入る）、注文履歴・納期・請求予定金額・請求書、取消・変更の依頼
- **現場QR注文** `/q/<トークン>` — ログイン不要。現場に貼ったQRから職人さんが注文
- **仕入先回答ページ** `/r/<トークン>` — ログイン不要。発注書メールのリンクから納期・仕入単価・代替品・送料を入力、出荷連絡

## 動かし方（手元のPC）

必要なもの: **Node.js 22.9 以上**

```bash
cd one-sto-plus
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。初回起動時はデモデータ（架空の会社・商品）が入ります。

| 画面 | ログインID | パスワード |
|---|---|---|
| 社員（管理者） | `admin` | `onesto-admin`（`ADMIN_PASSWORD` で変更） |
| 社員（所長） | `sato` | `demo1234` |
| 社員（営業） | `suzuki` | `demo1234` |
| お客様ポータル | `mirai` | `demo1234` |

- デモデータを入れ直す: `npm run seed`
- 空の状態（管理者のみ）から始める: `npm run seed:empty`
- テスト: `npm test`（見積 → 受注 → 発注 → 仕入先回答 → 出荷 → 売上 → 請求 → 入金、ポータル・QR・予算・AI読み取りの流れを一時データベースで確認）

## 設定（環境変数）

`.env.example` を `.env` にコピーして編集します（`npm start` が自動で読み込みます）。

| 変数 | 内容 |
|---|---|
| `BASE_URL` | 公開URL。メール内のリンク（回答ページ・ポータル・請求書）に使います |
| `ADMIN_PASSWORD` | 初回起動時に作る管理者のパスワード |
| `SEED_DEMO` | `0` にすると初回起動時にデモデータを入れません（本番用） |
| `ANTHROPIC_API_KEY` | AI読み取り（Claude API）のキー。未設定だとAI読み取りは使えません |
| `AI_MODEL` | AI読み取りのモデル（既定 `claude-opus-5`） |
| `SMTP_HOST` `SMTP_PORT` `SMTP_SECURE` `SMTP_USER` `SMTP_PASS` `MAIL_FROM` | メール送信。未設定の場合は送信せず、設定画面の「送信したメール」に記録だけ残します |
| `DATA_DIR` | データの保存先（既定 `./data`）。毎日 `DATA_DIR/backups` に自動バックアップ（14日分） |

## 本番での公開

お客様・仕入先がアクセスするため、インターネットから見えるサーバーに置き、**HTTPS** で公開してください。

- **Docker**: `docker build -t one-sto-plus . && docker run -p 3000:3000 -v onesto-data:/data --env-file .env one-sto-plus`
- **Render / Railway / Fly.io など**: Node.js アプリとしてデプロイし、永続ディスクを `DATA_DIR` に割り当てます
- **VPS（さくらのVPS・ConoHa など）**: Node.js 22 を入れて `npm ci && npm start`。nginx などでHTTPS化し、pm2 や systemd で常駐させます

データは SQLite（1ファイル）に保存されます。`DATA_DIR` をバックアップ対象にしてください。

> **Excel 読み込みライブラリについて**: npm で配布されている `xlsx`（0.18.5）には既知の脆弱性があります（細工した Excel ファイルを読み込ませる攻撃）。
> Excel を読み込めるのはログインした社員だけですが、本番では公式配布の修正版に入れ替えてください（使い方は同じです）。
> `npm i https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz`

## 構成

```
server.js            起動・ルーティング
src/db.js            データベース（スキーマ）
src/services.js      業務ロジック（受注・発注・回答・売上・請求・入金）
src/ai.js            仕入先見積書のAI読み取り（Claude API）
src/routes/          API（マスター・見積・受発注・請求・予算・社外向け・帳票）
public/              社員向け画面（index.html + js/）
public/portal/       お客様ポータル・現場QR・仕入先回答ページ
public/manual/       操作マニュアル
test/                通しテスト
```

帳票（御見積書・発注書・請求書・納品書・現場QR）はブラウザの「印刷 → PDFに保存」でPDFになります。
